# 2D FullMesh Clos Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a selectable `2d-fm-clos` topology type with 2D same-index-card full mesh links, 2D routing modes, simplified visualization, and updated documentation.

**Architecture:** Extend the existing config/topology/routing/visualization modules instead of replacing the current 1D behavior. Reuse the existing simulation engine because it already consumes routed paths and graph link bandwidths.

**Tech Stack:** Python 3, NetworkX, Plotly, pytest.

---

## File Structure

- Modify `multirail_topology/config.py`: add topology type, 2D domain size, 2D FM bandwidth, visualization detail.
- Modify `multirail_topology/topology.py`: add 2D FM domains and same-index cross-node full mesh links.
- Modify `multirail_topology/routing.py`: add `source-2dfm-jump` and `destination-2dfm-jump`.
- Modify `multirail_topology/visualize.py`: default simplified layout, switches centered, nodes split above/below.
- Modify `main.py`: CLI switches for topology type, 2D domain size/bandwidth, visualization detail.
- Modify `README.md`: describe 1D and 2D topologies and new parameters.
- Add/modify tests in `tests/test_topology.py`, `tests/test_routing.py`, `tests/test_cli.py`.
